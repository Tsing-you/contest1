这是一款心率血氧可视化分析软件，融合人工智能技术，实现从数据处理到智能分析再到输出的功能。通过可穿戴设备来监测和获得数据，进而传给我的分析软件，然后进行处理分析。在此过程中，本地建模分析与AI技术共同使用，呈现分析结果，体现智能化。 
软件具体分为五个板块，分别是数据概览与分析结果、可视化分析、AI健康建议、生成报告与发送邮件。在“数据概览与分析结果”这一板块中，对心率血氧数据进多维度分析，运用各种模型分析心血管风险，进行心率预测，并根据实际情况进行预警。在“可视化分析”这一板块中，生成多个可视化图表。在“AI 健康建议”这一版块中，调用智谱清言的API接口，传入本地建模分析的相关结果作为参数，让 AI 根据分析结果和异常记录给出通俗易懂且详尽的个性化健康建议。 在“生成报告”“发送邮件”这两个板块中，为分析数据的输出处理。
